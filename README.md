# Белая линия

Законченный одностраничный концепт семейной стоматологии для портфолио. React 19, Vite, TypeScript strict, CSS Modules. Спецификация: `AGENTS.md`, `STRUCTURE.md`, `DESIGN.md`; эти файлы сохранены без изменения.

## Запуск

Нужен Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://127.0.0.1:5173).

```sh
npm run typecheck
npm run build
npm run preview
npm test
```

Браузерные тесты используют установленный Microsoft Edge через Playwright. На другой системе замените `channel: 'msedge'` в `playwright.config.ts` на установленный Chromium и при необходимости выполните `npx playwright install chromium`.

## Реализовано

Все секции спецификации: выбор пяти ситуаций, динамический маршрут из трёх услуг, полный каталог и фильтры, четыре демонстрационных специалиста, первый визит, три пары учебных изображений до/после, оборудование и безопасность, 14 цен в пяти группах, восемь FAQ, форма, контакты, схема карты и footer. На мобильном — модальное меню с нативным удержанием фокуса, Escape и возвратом фокуса, а также нижняя CTA после hero; CTA скрывается у формы, контактов и подвала.

Выбор проблемы обновляет рекомендации и направление формы. Выбор услуги или специалиста сохраняется в состоянии страницы и показывается в форме. Направление можно изменить. Статусы озвучиваются коротким live region, выбранные кнопки имеют aria-pressed. FAQ поддерживает несколько открытых ответов. Все элементы доступны с клавиатуры.

Форма проверяет имя, телефон, направление, время, комментарий и согласие. При ошибке фокус попадает на первое неверное поле; введённые значения остаются. Обработка длится 750 ms локально; повторная отправка блокируется. Подтверждение явно сообщает: «Данные не были отправлены или сохранены». После успеха имя, телефон и комментарий удаляются из состояния; кнопка повторного заполнения полностью очищает форму, ошибки и выбранное направление. Это намеренный единообразный вариант reset из AGENTS.md.

## Архитектура

- `src/app/App.tsx` — композиция страницы и общий выбор.
- `src/components/` — логичные секции и их CSS Modules.
- `src/data/` — типизированные проблемы, услуги, врачи, цены, FAQ, галерея и общие тексты.
- `src/types/content.ts` — модели.
- `src/styles/` — reset, локальные шрифты и токены.
- `tests/site.spec.ts` — сценарии, адаптивность и axe.
- `public/images/` — оптимизированные изображения.
- `ASSETS.md` — происхождение и промпты изображений, лицензия Onest.

## GitHub Pages

Репозиторий: [miffis-gg/belaya-liniya](https://github.com/miffis-gg/belaya-liniya). Адрес сайта: [miffis-gg.github.io/belaya-liniya](https://miffis-gg.github.io/belaya-liniya/).

Публикация настроена через Settings → Pages → GitHub Actions. После каждого push в `main` workflow `.github/workflows/pages.yml` устанавливает зависимости, проверяет TypeScript, собирает `dist` и обновляет сайт. Состояние сборки доступно во вкладке Actions репозитория.

По умолчанию `base: './'`: ресурсы работают и на домене, и под именем репозитория. Для явного пути скопируйте `.env.example` в `.env` и задайте `VITE_BASE_PATH=/repository-name/`. Для production можно использовать `.env.production` или переменную сборки. Пути изображений формируются через `import.meta.env.BASE_URL`; шрифты Vite преобразует при сборке. Прямое открытие и обновление единственного URL страницы не требуют SPA fallback. Canonical указывает на адрес GitHub Pages; при переносе сайта измените его в `index.html`.

## Честность и ограничения

Все специалисты, стаж, услуги, цены, адрес и изображения — учебные данные. Реальных отзывов, рейтингов, медицинских гарантий, лицензий и статистики нет. Контакты не кликабельны и никому не принадлежат; карта не связана с географией. Backend, CMS, реальные слоты, онлайн-оплата и отправка отсутствуют.

Форма не делает сетевых запросов, не использует cookies, localStorage, sessionStorage или сторонние сервисы. Значения существуют только в памяти страницы; не вводите реальные персональные данные для демонстрации. Без JavaScript доступно честное статическое описание с просьбой включить JavaScript для интерфейса.

Работа выполнена с `impeccable` (new-work, craft floor, адаптация, аудит и полировка), `imagegen` и `context-mode`. Локальная часть Sites использована как руководство для preview; hosting не подключался. Автоматический launcher impeccable не запустился из-за отсутствия движка и прав на служебный каталог, поэтому спецификация прочитана напрямую и проверки выполнены доступными средствами. Утверждённый DESIGN.md не заменялся.
